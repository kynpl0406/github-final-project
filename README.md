# Simple Interest Calculator

A simple Bash script that calculates the simple interest given the principal amount, annual rate of interest, and time period in years.

## Disclaimer
**Do not use this in production.** This script is for sample and educational purposes only.

## Prerequisites
To run this script, you need to have a Unix-like operating system with:
* **Bash** shell environment.
* **`bc`** (Basic Calculator) installed for floating-point math operations.

*(Note: `bc` is usually pre-installed on most Linux distributions and macOS).*

## How to Run
1. Clone this repository or download the script file (e.g., `simple-interest.sh`).
2. Open your terminal.
3. Navigate to the directory where the script is located.
4. Give execute permission to the script:
   ```bash
   chmod +x simple-interest.sh
